# Is power-saver mode worth it? (COEN/ELEC 330 project)

From the first 5 seconds of a program, our model predicts how much energy Ubuntu's
power-saver mode would save and how much slower the program would get.

- **Website:** https://testcoen330deployment.streamlit.app
- **Measure your own program (Linux):**
  `curl -sSL https://raw.githubusercontent.com/genyvic/COEN_330_deployment/main/deployment/install.sh | sudo bash`

Everything (setup, VMware test, example input/output, limitations) is in
[deployment/README.md](deployment/README.md).
